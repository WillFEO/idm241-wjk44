Microinteractions Alpha: The Pinterest Card

Object: A single pin card in the Pinterest home feed/search results grid (logged-in user).

Scope: Hovering on and off of an unsaved pin. The buttons inside the pin are not included in this scope.

The Link

https://www.pinterest.com/

This link will open in a new tab. You will need to create a free account to view the content and microinteractions.

Locating the Object

Once you are logged in, locate any pin (one of the cards filling the screen) and move your mouse on and off of it to see the microinteraction.

The Microinteraction Breakdown

Triggers

The microinteraction is user-initiated and driven by the mouse cursor on an unsaved pin.

  • Hover ON
  • Hover OFF

Rules

  • Hover ON
    • The cursor changes from default arrow to pointing-finger hand
    • A vertical gradient overlay appears over the pin, darkest at the top and fading to transparent at the bottom
    • Three controls appear on top of the gradient: a board selector dropdown in the top left, a red "Save" button in the top right, and a white Share button in the bottom right
  • Hover OFF
    • The cursor changes back to default arrow
    • The vertical gradient overlay dissapears
    • The controls dissapear, returning the pin to its original state

The "..." button below the card is not part of this microinteraction, and stays visible and unchanged in both states.

Feedback

  • Hover ON
    • The cursor changes from default arrow to pointing-finger hand
    • A vertical gradient overlay appears over the pin, darkest at the top and fading to transparent at the bottom
    • Three controls appear on top of the gradient: a board selector dropdown in the top left, a red "Save" button in the top right, and a white Share button in the bottom right
  • Hover OFF
    • The cursor changes back to default arrow
    • The vertical gradient overlay dissapears
    • The controls dissapear, returning the pin to its original state

The feedback for this microinteraction is only visual; there is no auditory or haptic feedback.

Loops and Modes

Loops

  • Every pin in the Pinterest feed/search results grid has this same microinteraction.

Modes

  • Unsaved Mode: The overlay shows a red "Save" button as described above.
  • Saved Mode: If the user has already saved the pin, the "Save" button is replaced with a "Saved" button, which is a dark grey instead of red.

NOTE:

The buttons revealed on hover have their own hover/click states. Those are separate microinteractions and are outside of this scope.
