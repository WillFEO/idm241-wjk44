Microinteractions Alpha Build: The Pinterest "Pin" Card

The Microinteraction Breakdown

Triggers

The microinteraction is user-initiated and driven by the mouse cursor on an unsaved pin.

  • Hover ON
  • Hover OFF

Rules

  • Hover ON
    • The cursor changes from default arrow to pointing-finger hand
    • A vertical gradient overlay appears over the pin, 40% opacity at the top (rgba(0, 0, 0, 0.4)) and fading to 5% at the bottom (rgba(0, 0, 0, 0.05))
    • Three buttons appear on top of the gradient: a board selector dropdown in the top left (white #FFFFFF text with a downward chevron), a #E60023 red "Save" button with #FFFFFF white text in the top right, and a #FFFFFF white Share button with a #111111 black icon in the bottom right
  • Hover OFF
    • The cursor changes back to the default arrow
    • The vertical gradient overlay disappears
    • The buttons disappear, returning the pin to its original state

The "..." button below the card is not part of this microinteraction, and stays visible and unchanged in both states.

Feedback

  • Hover ON
    • The cursor changes from default arrow to pointing-finger hand
    • A vertical gradient overlay appears over the pin, 40% opacity at the top (rgba(0, 0, 0, 0.4)) and fading to 5% at the bottom (rgba(0, 0, 0, 0.05))
    • Three buttons appear on top of the gradient: a board selector dropdown in the top left (white #FFFFFF text with a downward chevron), a #E60023 red "Save" button with #FFFFFF white text in the top right, and a #FFFFFF white Share button with a #111111 black icon in the bottom right
  • Hover OFF
    • The cursor changes back to the default arrow
    • The vertical gradient overlay disappears
    • The buttons disappear, returning the pin to its original state

The feedback for this microinteraction is only visual; there is no auditory or haptic feedback.

Loops and Modes

Loops

  • None

Modes

  • Unsaved Mode: If a pin has not yet been saved, the hover overlay shows a red #E60023 "Save" button as described above.
  • Saved Mode: If the user has already saved the pin, the "Save" button is replaced with a "Saved" button, which is a dark grey instead of red.

NOTE:

The buttons revealed on pin hover have their own hover/click states. Those are separate microinteractions and are outside of this scope.

Pinterest uses its own font, Pin Sans, which isn't publicly available. This build uses Inter, a close free alternative.
