Microinteractions Beta: The Pinterest "Pin" Card

Objects: A single pin card in the Pinterest home feed/search results grid (logged-in user), its board selector, and its "Save" button.

Scope: Hovering on and off of the pin, its board selector, and its "Save" button, and clicking "Save" to save and unsave the pin. The Share and "..." buttons are not included in this scope.

The Link

https://www.pinterest.com/

This link will open in a new tab. You will need a free account to view the content and microinteractions.

Locating the Object

Once you are logged in, move your mouse onto any unsaved pin and click "Save". The current version has no transitions, and its save confirmation appears at the bottom of the screen.

The Microinteraction Breakdown

Triggers

Pin

  • Hover ON
  • Hover OFF

Board Selector

  • Hover ON
  • Hover OFF

"Save" Button

  • Hover ON
  • Hover OFF
  • Click

Rules

Pin

  • Hover ON
    • The cursor changes from default arrow to pointing-finger hand
    • A vertical gradient overlay fades in over 150ms, 40% opacity at the top (rgba(0, 0, 0, 0.4)) and fading to 5% at the bottom (rgba(0, 0, 0, 0.05))
    • Three buttons fade in with the overlay: a board selector in the top left (#FFFFFF white text and chevron on a 30% black background, rgba(0, 0, 0, 0.3)), a #E60023 red "Save" button with #FFFFFF white text in the top right, and a #FFFFFF white Share button with a #111111 black icon in the bottom right
  • Hover OFF
    • The cursor changes back to the default arrow
    • The vertical gradient overlay fades out over 150ms
    • The buttons fade out with the overlay, returning the pin to its original state

Board Selector

  • Hover ON
    • The background darkens to 50% black (rgba(0, 0, 0, 0.5)) over 150ms
  • Hover OFF
    • The background fades back to 30% black (rgba(0, 0, 0, 0.3)) over 150ms

"Save" Button

  • Hover ON
    • The button darkens from #E60023 red to #AD081B red over 150ms
  • Hover OFF
    • The button fades back to #E60023 red over 150ms
  • Click (Unsaved)
    • The button shrinks to 95% over 100ms while pressed and springs back over 150ms on release
    • The text changes to "Saved!" and pops to 115% size, settling back over 300ms
    • Six short #FFFFFF white lines burst out from the button and fade away
    • The button fades to #333333 dark grey and widens to fit the text over 150ms, staying anchored to the top right corner
    • After 1 second, "Saved!" fades into "Saved" over 150ms
    • Backend: the pin is added to the board named in the board selector ("Profile")
  • Click (Saved)
    • The button shrinks to 95% over 100ms while pressed and springs back over 150ms on release
    • The text fades back to "Save" and the button narrows to fit over 150ms
    • The button fades from #333333 dark grey to #AD081B red over 150ms
    • Backend: the pin is removed from that board

The Share button and the "..." button below the card are not part of this microinteraction. Share fades in and out with the overlay, and "..." stays visible and unchanged in all states.

The backend updates are hypothetical, since this redesign is a concept and is not connected to Pinterest.

Loops and Modes

Loops

  • None

Modes

  • Unsaved Mode: If a pin has not yet been saved, the hover overlay shows a #E60023 red "Save" button.
  • Saved Mode: If the user has already saved the pin, the hover overlay shows a #333333 dark grey "Saved" button instead.
